# AI Gallery

Find any photo or screenshot on your Android phone by describing it:

> *"the screenshot of my conversation with Jamie"* · *"the restaurant menu I took last summer"* ·
> *"the screenshot where someone sent me their bank details"* · *"the red car"*

AI Gallery reads the text inside your screenshots, understands what your photos show and
searches them in natural language — **entirely on the phone**. The release app has no
internet permission: images, recognised text and the search index never leave the device.

## How it works

| Step | Technology |
|---|---|
| Gallery access | Android MediaStore via `photo_manager` (images only, Android 14 partial access supported) |
| Text in images | Google ML Kit text recognition, bundled Latin model (offline) |
| Visual understanding | SigLIP B/16 image/text encoders (Google, Apache-2.0), int8, ONNX Runtime |
| Screenshot understanding | OCR layout → screen type (chat, map, web, shop, social, settings, receipt, email, menu), chat title and messages |
| People | Face *count* only (ML Kit face detection); no identity, no attributes |
| Index | SQLite (FTS5 full-text search) + in-memory cosine vector index |
| Search | Query understanding (visual / text-in-image / conversation / hybrid, head noun, dates, people) → the right evidence for each intent, calibrated thresholds, a "why this matched" explanation for every result ([docs/SEARCH_DESIGN.md](docs/SEARCH_DESIGN.md)) |

Details: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/AI_PIPELINE.md](docs/AI_PIPELINE.md),
[docs/DATABASE.md](docs/DATABASE.md), product and design: [docs/PRD.md](docs/PRD.md),
[docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md), [docs/SCREENS.md](docs/SCREENS.md).

## Requirements

- Flutter 3.47 (stable) / Dart 3.13, Android SDK 36, JDK 17+
- Android 8.0 (API 26) or newer on the device; 64-bit device recommended
- Python 3.13 (only to generate the model files once)

## Setup

```bash
flutter pub get

# 1. Generate the bundled model files (one-off, ~815 MB download -> 229 MB of assets).
#    The weights are not stored in git; see "Model licence" below.
python -m venv tool/.venv
tool/.venv/Scripts/python -m pip install -r tool/requirements.txt   # bin/python on macOS/Linux
tool/.venv/Scripts/python -I tool/fetch_models.py siglip_b16
tool/.venv/Scripts/python -I tool/quantize_siglip.py
tool/.venv/Scripts/python -I tool/install_assets.py

# 2. Run
flutter run
```

Without step 1 the app still builds and works, but in text-only mode (search by text found
in images, dates and type; no visual search). Search results show a notice when that happens.

The first Android build also downloads the SQLite binary used by `package:sqlite3`
through its build hook, so it needs network access once.

## Tests

```bash
flutter analyze
flutter test                                        # unit + widget tests
flutter test integration_test/gallery -d <device>   # on-device: MediaStore access
flutter test integration_test/ml -d <device>        # on-device: model vs reference embeddings
```

On-device tests need `READ_MEDIA_IMAGES` granted right after install:
`adb shell pm grant com.bachar02.ai_gallery android.permission.READ_MEDIA_IMAGES`.

A realistic test gallery (chat screenshots with known text, dated photos) and the expected
answers for the product's example queries are generated by
`tool/.venv/Scripts/python tool/fixtures/make_fixtures.py --push` (needs a running emulator).

## Release builds

```bash
flutter build apk --release --split-per-abi   # one APK per CPU architecture
flutter build appbundle --release             # for Google Play
```

Signing reads `android/key.properties` (not committed):

```properties
storePassword=...
keyPassword=...
keyAlias=upload
storeFile=/absolute/path/to/upload-keystore.jks
```

Without it, release builds fall back to the debug key (fine for local testing, not for
distribution). See [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md).

## Privacy

- No internet permission in release builds; no analytics, no crash reporting, no accounts.
- The index (OCR text, embeddings) lives in app-private storage, is excluded from Android
  backup and device transfer, and is written with SQLite `secure_delete`.
- Settings → *Delete local index* removes everything the app has generated.
- Names are only ever matched when they appear as text in an image; the app does not
  recognise faces or identify people.

## Model licence

The visual model is Google's SigLIP base patch16-224 (`google/siglip-base-patch16-224`),
released under the Apache License 2.0; the ONNX export is `Xenova/siglip-base-patch16-224`
and the app bundles int8 copies made by `tool/quantize_siglip.py`. The licence text and a
notice describing the modifications are in `assets/models/siglip_b16/` and on the in-app
licence page. (Version 1 used MobileCLIP-S0, whose current weights licence is research-only.)
